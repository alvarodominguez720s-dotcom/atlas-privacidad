# atlas-privacidad

La web de Atlas en GitHub Pages:

- `index.html` y `en/index.html`: presentación de la app (español e inglés).
- `politica-privacidad.html` y `borrar-cuenta.html`: política de privacidad y cómo borrar la cuenta. Se generan desde el repositorio de la app.
- `sitemap.xml`: para dar de alta la web en Google Search Console.
